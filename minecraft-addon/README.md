# Minecraft Bedrock Add-On

Esta carpeta se reservará para un Add-On de Minecraft Bedrock basado en Script API.

## Objetivos futuros
- Detectar eventos y datos del mundo que la API permita consultar.
- Proporcionar contexto adicional para los consejos de Katia.
- Mantener el Add-On separado de la aplicación Android.

Un Add-On no puede crear por sí solo una ventana flotante de Android ni leer directamente todos los píxeles de la pantalla. Esas funciones corresponden a la aplicación Android y a los permisos del sistema.
