# Katia Minecraft Companion — Plan

## Objetivo
Crear una compañera de Minecraft Bedrock para Android, con una interfaz flotante púrpura y una imagen fija de Katia.

## Etapas
1. Crear la base de la aplicación Android en Kotlin.
2. Implementar una interfaz flotante mediante los permisos de Android.
3. Añadir conversación por voz.
4. Añadir captura de pantalla mediante MediaProjection, con autorización explícita.
5. Explorar la integración con un Add-On de Minecraft Bedrock.
6. Incorporar un backend seguro y memoria cuando la app básica esté probada.

## Decisiones
- Katia tendrá una apariencia púrpura fija.
- No se implementarán cambios de expresiones faciales.
- La captura de pantalla y el micrófono requerirán autorización del usuario.
- Las claves secretas permanecerán en el servidor, nunca dentro del APK.

## Estado
Plan inicial. La aplicación todavía no está implementada.
