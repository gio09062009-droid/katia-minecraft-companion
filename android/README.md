# Aplicación Android

La aplicación principal se desarrollará en Kotlin.

## Funciones previstas
- Panel flotante opcional sobre Minecraft.
- Interfaz púrpura con imagen fija de Katia.
- Entrada y salida de voz.
- Captura de pantalla mediante el permiso del sistema Android.

## Seguridad
- Solicitar permisos cuando se necesiten.
- Indicar claramente cuándo se usa el micrófono o la captura de pantalla.
- No incluir tokens ni claves privadas en la aplicación.

Esta carpeta recibirá el proyecto Android Studio en la siguiente etapa.
