# Backend

El backend se implementará con Cloudflare Workers.

## Responsabilidades previstas
- Recibir solicitudes de la aplicación.
- Comunicarse con el servicio de IA elegido.
- Validar solicitudes y aplicar límites de uso.
- Mantener las credenciales secretas del lado del servidor.

No colocar claves API en la aplicación Android ni en archivos públicos del repositorio.
